## ◈ About

This repository contains my personal portfolio website — a digital representation of my work, technical abilities, experience, and journey as a developer.

The goal is not simply to present information, but to create an experience that feels **modern, intentional, responsive, and memorable**.

The interface combines clean visual design with interactive elements to create a portfolio that reflects both **engineering discipline** and **creative thinking**.
